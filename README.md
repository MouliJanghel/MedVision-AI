# AI-Assisted Medical Imaging and Diagnosis System

## Project Overview

An AI-assisted medical imaging system using
deep learning for classification, segmentation,
and explainable AI.

## Technologies

- Python
- PyTorch
- MONAI
- DenseNet121
- 3D U-Net
- Grad-CAM
- Orthanc
- FastAPI
- React
- Docker
- DVC

## Features

1. Medical image classification
2. Medical image segmentation
3. Grad-CAM heatmap visualization
4. Doctor approval and rejection
5. Audit logging

## Disclaimer

For educational purposes only.
Not intended for clinical diagnosis.
